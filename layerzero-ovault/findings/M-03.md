# M-03: Retry path fails when `dstEid == HUB_EID`

- Source: [Cantina public report](https://cantina.xyz/portfolio/e4d93441-0fe3-4b64-bf98-fa31ecef4fb5)

## Issue

The normal path treats `dstEid == HUB_EID` as a special local route, but retry logic can still fall back into generic peer validation. That creates a divergence between happy path and recovery path.

## Invariant

Retry must preserve the same routing semantics.
