# M-05: Inconsistent slippage checks can create stuck-funds behavior

- Source: [Cantina public report](https://cantina.xyz/portfolio/e4d93441-0fe3-4b64-bf98-fa31ecef4fb5)

## Issue

A local path can accept parameters that later fail deeper in debit / normalization logic. If two stages disagree on slippage semantics, the flow can move forward into a state that cannot complete.

## Invariant

All slippage-sensitive stages of the same send flow should agree on the same effective amount before execution commits.
