# H-01: Refund path can permanently strand user funds

- Source: [Cantina public report](https://cantina.xyz/portfolio/e4d93441-0fe3-4b64-bf98-fa31ecef4fb5)

## Issue

`refund()` rebuilds the refund operation from a mutated `sendParam` instead of the preserved refund payload. In the bad path, `sendParam.amountLD` is already zeroed, so recovery no longer has the original amount.

## Invariant

If a failed flow enters refund mode, refund logic must use the intact saved refund payload, not a mutated runtime copy.
