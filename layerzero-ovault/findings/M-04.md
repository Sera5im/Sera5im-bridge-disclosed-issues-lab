# M-04: Native value can become trapped and must be paid again on retry

- Source: [Cantina public report](https://cantina.xyz/portfolio/e4d93441-0fe3-4b64-bf98-fa31ecef4fb5)

## Issue

The failed-message path can strand already supplied native value, while retry still asks for fresh `msg.value`. The user can lose access to the first payment and still be forced to pay again.

## Invariant

Recovery must reuse or refund prior native value.
