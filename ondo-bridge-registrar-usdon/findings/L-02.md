# L-02: Hardcoded conversion rate assumes 6-decimal USDC everywhere

- Source: [Cantina public report](https://cantina.xyz/portfolio/91210482-130b-478a-848c-773029679a90)

## Issue

`USDonConverter` hardcodes `USDC_TO_USDON_CONVERSION_RATE = 1e12`, which assumes the bridged USDC always uses 6 decimals. That assumption can break on chains where the deployed token precision differs.

## Invariant

If converter math depends on token decimals, the rate must match the actual deployed token precision on that chain.
