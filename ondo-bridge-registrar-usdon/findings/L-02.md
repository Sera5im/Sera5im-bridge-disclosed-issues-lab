# L-02: Hardcoded conversion rate assumes 6-decimal USDC everywhere

## Summary

`USDonConverter` hardcodes `USDC_TO_USDON_CONVERSION_RATE = 1e12`, which assumes the target `USDC` token always uses 6 decimals.

That assumption does not hold on every chain.

## Invariant

If converter math depends on token decimals, the rate must match the actual deployed token precision on that chain.

## Impact

Deployments on chains with 18-decimal `USDC` can miscalculate conversion amounts and break converter behavior.

## Fix direction

Read token decimals dynamically during deployment or initialization and derive the conversion rate from the real token precision.
