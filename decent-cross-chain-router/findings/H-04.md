# H-04: Reserve shortfall can strand bridged value inside the destination-side adapter

- Source: [Code4rena public report](https://code4rena.com/reports/2024-01-decent)

## Issue

If destination `WETH` reserves are insufficient, the fallback path sends received `dcntEth` to `_to`. In payload-bearing messages, `_to` is the execution target, not the real user refund address, so value can get stranded inside the adapter.

## Invariant

Fallback must preserve user ownership of bridged value.
