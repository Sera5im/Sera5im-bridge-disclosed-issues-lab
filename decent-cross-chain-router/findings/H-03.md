# H-03: Failed destination execution refunds bridged WETH to the wrong address

- Source: [Code4rena public report](https://code4rena.com/reports/2024-01-decent)

## Issue

When destination execution fails, the executor refunds bridged WETH to `_from`. In the vulnerable path, `_from` is not the real user refund address, but an internal bridge-side value embedded into the payload.

## Invariant

Refunds must go to the user, not an internal address.
