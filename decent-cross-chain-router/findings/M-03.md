# M-03: Public receiveFromBridge path bypasses fee collection and signed instruction enforcement

- Source: [Code4rena public report](https://code4rena.com/reports/2024-01-decent)

## Issue

`UTB.receiveFromBridge(...)` is publicly callable and goes straight into `_swapAndExecute(...)`. Unlike normal user paths, it does not pass through fee collection or signature validation.

## Invariant

Any user-reachable path that executes the same swap / execute logic must preserve the same fee checks and authenticated instruction checks.
